# Sign Video Assets Folder

Place video files (.mp4) representing each sign in this folder.

The filename must match the relative paths configured in `config/sign_vocabulary.json`.

For example:
- `hello.mp4` -> Maps to `HELLO`
- `thank_you.mp4` -> Maps to `THANK_YOU`
- `sorry.mp4` -> Maps to `SORRY`
- etc.

Supported video format: H.264 encoded MP4 (highly recommended for HTML5 video playback compatibility).
